# pages/ — автогенерируемые страницы (data-derived)

Файлы `pages/<translator>.html` **генерируются автоматически** из
`data/<translator>_markup_50.json` командой:

```sh
python scripts/build_pages.py
```

Это воспроизводимое **табличное представление данных** (URN, 4 оси, IAST, текст
примечания) — единый источник истины для проверки разметки. **Не редактировать
руками** (правки затрутся при пересборке); правьте JSON-данные и пересоберите.

## Чем отличаются от `*_commentary_analysis.html` в корне

| | `pages/<name>.html` (здесь) | `<name>_commentary_analysis.html` (корень) |
|---|---|---|
| происхождение | сгенерировано из JSON | написано вручную |
| содержание | 50-нотная выборка + статистика | развёрнутое аналитическое эссе |
| статус | пересобираемо, data-derived | основной аналитический артефакт |
| правка | через данные | вручную |

Рукописные страницы содержательно богаче (полные профили, исторический контекст,
сопоставления) и **не** заменяются генератором — он сознательно пишет в отдельную
директорию, чтобы их не затронуть.
