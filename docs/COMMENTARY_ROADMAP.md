## 1. Манифест стратегии

Аппарат Сундараканды — **двухъярусный гибрид** (модель II, решена 2026-07-01):
- **Ярус 1 (печатный минимум)** — собственные примечания Леонова/Костиной: **1058 нот** по 68 песням
  (~37% плотности; [`data/leonov_own_notes.json`](https://github.com/gasyoun/CommentaryStrategies/blob/main/data/leonov_own_notes.json)).
  Это и есть бенчмарк «уровня Леонова».
- **Ярус 2 (цифровой филологический слой)** — наш генерируемый аппарат: лексический (фаза 1) +
  комментаторский диалог (фаза 2), всё `review_required`, в регистре «Литературных памятников»
  (эталон — Гринцер).

**Фирменная черта аппарата Леонова — диалог с санскритскими комментаторами** («в „Тилаке“ — X, в
„Широмани“ — Y»). Это то, чего почти нет у Гринцера, и это ось нашей стратегии: ярус 2 систематизирует и
расширяет именно этот слой, не переписывая печатный ярус 1.

## 3. Редакционная политика — черновые рекомендации [на ратификацию]

По вопросам Костиной и Леонова из памятки. По каждому — **рекомендация по умолчанию** (прецедент
Гринцера/ЛП) + основание; финальное слово за Леоновым/Костиной.

**Реалии и ссылки (Костина §2.1).** Рекомендация: перекрёстные ссылки на предыдущие Канды давать по
локусу стиха («см. примеч. к III.x.y»); для **неопубликованных** Канд ссылаться по номеру шлоки с пометой
«перевод не опубл.». Первое вхождение реалии комментируется, далее — без. *[ратифицировать]*

**Параллельные места с другими Кандами (§2.2).** Рекомендация: отмечать **выборочно** — только значимые
или формульные совпадения, единым маркером «ср. также …». Не превращать в конкорданс. *[ратифицировать]*

**Расхождения редакций — критическое / южное / Гитапресс (§2.3, Леонов).** Рекомендация: отмечать
**существенные** — выпавшая целиком глава, выпавшая/добавленная шлока, вставки Гитапресс; мелкие
орфографические расхождения не отмечать. **Инструмент готов** (`scripts/compare_editions.py` →
[`data/edition_comparison/`](https://github.com/gasyoun/CommentaryStrategies/blob/main/data/edition_comparison/README.md)):
критическое (GRETIL/Барода) vs южное (Леонов) = **66 vs 68 сарг, 2488 vs 2859 шлок (+371)**; южные сарги
№4 и №8 отсутствуют в критическом; 196 непрерывных южных пассажей без критич. аналога → готовые сноски
«в критическом издании (Барода) отсутствует». Гитапресс — отдельный источник (см. §7). *[ратифицировать формат сноски]*

**Расхождения переводов/толкований + обоснование выбора (§2.4).** Рекомендация: **да** — когда толкование
влияет на смысл перевода, давать краткое обоснование выбора. Это и есть ядро яруса 2 («в Тилаке X / в
Широмани Y» → какое чтение принял перевод). *[ратифицировать]*

**Когда давать буквальный перевод (§2.5).** Рекомендация: когда поэтический перевод расходится с
буквальным смыслом термина/кара́ки, важной для понимания, — по образцу Гринцера («букв. …»). *[ратифицировать]*

**Опущения в переводе (Костина, доп. 1).** Рекомендация: отмечать **последовательно** значимые опущения
(не стилистические сокращения), единым маркером; политику зафиксировать письменно (Гринцер, по замечанию
Костиной, непоследователен — мы делаем иначе). *[ратифицировать]*

**Стратегия эпитетов (доп. 2).** Рекомендация: **да** — при первом вхождении отмечать, если в оригинале
одно имя передано другим; далее без пометы. Опереть на уже готовый слой
[`data/ramayana_epithets.json`](https://github.com/gasyoun/CommentaryStrategies/blob/main/data/ramayana_epithets.json). *[ратифицировать]*

**Выпавшие главы/шлоки, вставки Гитапресс (Леонов).** Рекомендация: выпавшую главу целиком — отмечать
всегда; интересные расхождения шлок — отмечать; вставки Гитапресс маркировать как таковые. *[ратифицировать, ресурс-gated]*

**Литературоведческий слой — шабда-аланкары (Леонов).** Рекомендация: включить как отдельный тип
поэтологических примечаний (у Гринцера уникальный поэтологический слой ~12%, см. GRINTSER_PROFILE) — но как
**необязательный** ярус-2, точечно. *[ратифицировать]*

**«Волевое решение переводчика».** Рекомендация: где перевод выбирает вопреки части комментаторов —
помечать явно («переводчик следует …»). *[ратифицировать]*

## 4. «Эталонное» оформление примечания (памятка, стр. 13)

Единый формат (детали — PHASE2_METHOD §3.1): лемма в IAST-пратике → краткая русская глосса; при опоре на
комментатора — назвать его («по Тилаке»); «букв. …» для буквального перевода; «см. …» для перекрёстных
ссылок; 1–3 предложения; доля IAST ~12% (калибровка Гринцера). Запрещено: «М.: Наука 2022» для Леонова;
единственная косвенная форма — «Парибка».
