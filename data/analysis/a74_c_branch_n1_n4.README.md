## Методика

- Корпус: локальный клон `~/Documents/GitHub/dcs-conllu`, читается
  **git-пламбингом на пине** (`ls-tree -r -z` + `cat-file --batch`), как в свипе.
  Пин берётся из `rakshasa_dcs_form_sweep_2026-11-20.json` (`corpus.pin`):
  клон не на пине — **ненулевой выход**, числа не пишутся.
- Токены: строки с целым ID, только `*.conllu` (авто-парсы `*_parsed`
  пропущены — 7 227 файлов). Всего 5 688 416 токенов.
- Бакет свипа воспроизводится для сверки: FORM содержит «rākṣas» → 2 939,
  поровну с `totals.rākṣasa_family` свипа (`crosscheck_sweep.equal`).
- Класс вхождения — по **лемме**:
  - `simple` — лемма `rākṣasa` или `rākṣasī`;
  - `compound` — `rākṣasa-` / `rākṣasī-` первым или последним членом
    (`brahmarākṣasa`, `rākṣaseśvara`, `rākṣasavaktra`, `sa-rākṣasa`…); на стыке
    учтён сандхи (`rākṣasa` + `īśvara` → `rākṣaseśvara`);
  - `cross_morpheme` — подстрока «rākṣas» на стыке морфем (`sahasrākṣa`-,
    `dhūmrākṣa`-, `makarākṣa`-, `vajrākṣa`-, `puṣkarākṣa`-, `kuberākṣa`-,
    `rudhirākṣa`-): в счёт слова не входят.
- Для простого стема: `fem` = лемма `rākṣasī`; `noun` = UPOS NOUN;
  `adj` = UPOS ADJ. Написания `rākṣasam` / `rākṣasaṃ` различаются только в FORM
  и сходятся на лемме.
- Слои — **явные списки групп DCS** (`method.strata`); имя, которого нет в
  корпусе, останавливает прогон. Не перечисленное — `other`.

В архаическом ведийском слое существительного `rākṣasa-` **нет вовсе**; оба
вхождения — прилагательное в Айтарея-брахмане (AB 2.7: «sā vai rākṣasī vāc»).
До эпосов существительное-существо встречается в корпусе **один раз** —

**N2 — плотности.** Среди групп от 20 000 токенов Rāmāyaṇа вне конкуренции
(56,5 на 10 000); далее Mahābhārata 7,1 · Kathāsaritsāgara 7,0 ·
Bhāratamañjarī 6,7 · Harivaṃśa 4,0 · Matsyapurāṇa 3,2 · Garuḍapurāṇa 2,9.
Ранг эпосов по плотности держится — устойчивость к смене знаменателя (§6 скелета) подтверждена.

**N3 — «Махабхарата» по парвам** (простой стем, всего 814): Vana 205 (13,5 на 10 000) ·
Droṇa 163 (14,6) · Ādi 148 (8,8) · Bhīṣma 119 (15,6) · Śānti 53 · Anuśāsana 30 ·
Śalya 23 · Sabhā 19 · Udyoga 19 · прочие ≤ 10. Две «боевые» книги (Bhīṣma + Droṇa)
дают 282 вхождения (34,6 %), лесная книга — 205 (25,2 %): слово в «Махабхарате»
не исчерпывается лесными одиночками — треть его приходится на битвы, где оно
работает ярлыком противника. Числа для сверки с M02 §1.4.1 / §1.4.5.

**N4 — «Рамаяна»: DCS ↔ вульгата.** DCS несёт рамку сарг критического издания:
Bāla 76 · Ayodhyā 111 · Araṇya 71 · Kiṣkindhā 66 · Sundara **66** (у вульгаты 68) ·
Yuddha 116 · Uttara 100 = 606. Разность с переписью вульгаты (1 566) держится
на трёх кандах: Yuddha 662 против 877 (−215), Araṇya 214 против 277 (−63),
Sundara 298 против 326 (−28). Разные текстовые базы; расхождение описано, не сглажено.

**Оговорка, важная для M02.** Женский род в таблице переписи вульгаты (M02 §1.4.2,
колонка «из них rākṣasī») считается **подстрокой** «rākṣasī». По лемме в DCS
`rākṣasī` покрывает 144 токена «Рамаяны», а подстрокой ловится 101: косые формы
`rākṣasyaḥ` (14) · `rākṣasyo` (24) · `rākṣasyā` (4) · `rākṣasi` (1) подстрокой
не берутся. Для вульгаты пересчёт по лемме невозможен (другой текст); порядок
недоучёта показывает DCS: 144 / 109 ≈ 1,3. К M02 в этом юните не притронуто —
числа для решения автора.

  возбудитель одержимости и **тип темперамента/телосложения** (ярлык). В
  раса-шастре `rākṣasa` / `rākṣasī` — **технические названия**: сорта ртути,
  препараты, аппарат, операция, растение. Это и есть ответ N6 для этих слоёв:
  специальные значения, не гомонимы случайно, а устойчивая терминология.
