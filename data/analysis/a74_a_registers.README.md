- **Эпитеты**: запись `data/ramayana_epithets.json` отобрана, если её имя или строка

## Остатки

- **Классы словоформ — поверхностные.** Правило читает текст после стема, без разбора;
  список всех форм лежит в JSON (`forms`, `kanda_forms`) и поддаётся проверке глазами.
  Известные швы: `राक्षसमुख्यपालिताम्` (5.3.51, настоящий компаунд) идёт «формой
  склонения»; настоящая косвенная форма, склеенная сандхи с предыдущим словом,
  попала бы в «межморфемные» (в канде такой нет).
- **`राक्षसस्य`** — 4 раза в канде (2 в блоке); по контексту всюду род. п.
  «ракшаса» с лишним «स», вынесен в `irregular`.
- **Пустые `verse_id`.** В исходнике 8 объектов блока без номера (полустих отдельным
  объектом), 5 из них с вхождением; перепись их считает. Их локус — позиция в сарге и
  ближайший предыдущий номер (`by_sarga[*].items_without_verse_id` = 8;
  `occurrences[*].item`, `after_verse`; `occurrences_without_verse_id` = 5).
- **Имена.** Собраны двумя механическими шаблонами (`named_rule`); ракшаси,
  названная иначе, не поймается. В глоссе источника латиница без диакритики.
- **Классы носителей эпитетов** — чтение исполнителя (закрытый список в скрипте).
  Ростр источника — не полный список ракшас; дефекты источника не правились:
  «Марича и Субаху: два сына Сунды и Упасунды», «Ракшасы Марича и Субах: у -два сына
  Сунды и Упасунды».
- **Разные текстовые базы.** Юддха-срез и каталог DCS — критическая рамка (Сундара
  66 сарг), стражи — южная вульгата (68 сарг); по саргам не выравниваются.
- **N7** — речевой атрибуции нет.
- **A1 скелета:** сопоставление Rāmopākhyāna ↔ rakṣovaṃśa (L2) не сделано — вне миссии
  H8641.
