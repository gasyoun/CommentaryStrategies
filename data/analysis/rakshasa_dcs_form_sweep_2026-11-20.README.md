# rakshasa_dcs_form_sweep_2026-11-20 — DCS FORM-свип rākṣasa- (H8498)

_Created: 20-11-2026 · Last updated: 20-11-2026 · Executor: GLM 5.3 (opencode-go/glm-5.3) · Claim: `claims/H8498.20261120T1253Z`_

Числовой преп-юнит статьи M02 (том V ЛП «Сундараканда», §1.4.8/§6): локально
воспроизводимые числа встречаемости ракшас-лексики по корпусу DCS. Проза статьи
в этом юните не тронута — указатель из метадока на новые ключи добавит юнит
добора, не этот.

## Методика

- Корпус: локальный клон `~/Documents/GitHub/dcs-conllu` (полный DCS-conllu,
  270 групп, 15 900 канонических conllu-файлов на пине f6ec30f). Локальный
  sparse-checkout материализует только 2 группы — и лишь часть их файлов
  (в Rāmāyaṇa на диске 258 файлов из 606) — поэтому скрипт читает файлы
  **git-пламбингом на пине** (`ls-tree -r -z` + `cat-file --batch`),
  ничего не расширяя на диске и не завися от полноты checkout.
- Пин: runtime `git rev-parse HEAD` (паттерн H7924). Нет клона/пина —
  **ненулевой выход** (exit 3), нули не пишутся, числа не выдумываются.
- Токены: колонка FORM, только строки-токены (ID — целое). Multiword-склейки,
  комментарии и файлы `*_parsed` (авто-парсы, 7227 шт.) не считаются —
  «чистые формы», без смешения текст/глосса (урок досье §3).
- Бакеты (конвенция переписи 01-11, `rakshasa_census_vulgate_2026-11-01.py`):
  - `rākṣasa_family` — подстрока «rākṣas» (семейство rākṣasa-, включая rākṣasī);
  - `rākṣasī` — подмножество family (женский);
  - `rakṣas_neuter` — средний род rakṣas- (`rakṣas…|rakṣo|rakṣāṃsi`).

## Числовой журнал (ключи JSON)

| Ключ | Смысл |
|---|---|
| `corpus.pin` | sha коммита dcs-conllu, по которому считано (детерминирует всё) |
| `corpus.groups_total` / `corpus.conllu_files_scanned` | охват: групп / файлов |
| `headline.<Группа>.rākṣasa_family` | FORM-токены семейства в группе |
| `headline.<Группа>.rākṣasī` | из них женский rākṣasī |
| `headline.<Группа>.rakṣas_neuter` | формы ср. рода rakṣas- |
| `groups.<…>` | те же ключи по ВСЕМ группам корпуса (вкл. прочие) |
| `groups.<…>.forms[]` | детализация: форма → счёт по бакетам (только непустые) |
| `totals.rākṣasa_family` / `totals.rākṣasī` / `totals.rakṣas_neuter` | по корпусу целиком |
| `totals.groups_nonzero_family` | сколько групп содержат семейство |

Headline-группы (сверка с досье §3): `Rāmāyaṇa`, `Mahābhārata`,
`Kathāsaritsāgara` («Kathā-» досье), `Garuḍapurāṇa` («Garuda-» досье).

сверки трёх чисел без разбора файла.

## Досье-кросс-чек

Числа досье (Ram 131 / MBh 59 / Kathā 24 / Garuda 8) — веб-поисковые,
**НЕ печатные**; сверяются с локальными числами только как масштаб. Печать —
исключительно из этого JSON. Методологическая разница: досье считало
смешанно (текст + глоссы), здесь — чистые FORM-токены; равенства не ожидается.
