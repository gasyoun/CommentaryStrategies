# Критическое издание (GRETIL/Барода) ↔ южная вульгата (перевод Леонова) — Сундараканда

> Сравнение структуры двух принципиально разных изданий, обсуждавшееся в
> [`ramayana-leonov/Костина.txt`](https://github.com/gasyoun/CommentaryStrategies/blob/main/ramayana-leonov/%D0%9A%D0%BE%D1%81%D1%82%D0%B8%D0%BD%D0%B0.txt)
> (Леонов: критическое vs южное vs Гитапресс; выпавшие главы/шлоки). Построено
> [`scripts/compare_editions.py`](https://github.com/gasyoun/CommentaryStrategies/blob/main/scripts/compare_editions.py)
> (детерминированное выравнивание нормализованных IAST-шлок, difflib).
>
> **Источники (read-only):** критическое = GRETIL `ram_05_u.htm` (Барода, полукадры `5.SSS.VVVa/c`);
> южное = корпус `SamudraManthanam/.../05_ramayana-sundarakanda.jsonl` (текст, который переводит Леонов;
> классифицирован в RussianRamayana как «южная (вульгата)»).

## Итог по книге

| | Критическое (Барода) | Южное (вульгата) | Δ |
|---|---:|---:|---:|
| **Песней (сарг)** | **66** | **68** | **+2** |
| **Шлок** | **2488** | **2859** | **+371** |

- **Южное издание содержит на 2 песни больше (68 − 66): целые песни, отсутствующие в критическом.**
  Алгоритм помечает как «лишние» южные сарги № 4, № 8 (и, предварительно, № 60 — требует сверки: разница
  ровно +2, третий кандидат — шум сопоставления). После вставок нумерация сдвигается (крит. 4 = южн. 5 …).
- Содержательное выравнивание (канонизация `sanskrit_util.nfold` + fuzzy-назначатель по Jaccard, п.1):
  идентичных **1065** · вариантных **1043** (вкл. 22 fuzzy-пары) · транспозиции 9 южн./3 крит. ·
  «только в критическом» **377**.
- **Южные шлоки без выравнивания = 742, но они РАЗНЫЕ по природе:**
  - **307 — истинное структурное отсутствие** (лучший Jaccard к любой критич. шлоке < 0.25) →
    **безопасные сноски** «в критическом издании (Барода) отсутствует».
  - **435 — переформулировка** (Jaccard 0.25–0.5): та же шлока ЕСТЬ в критическом, но сильно
    переписана → это **разночтение, НЕ отсутствие**; сноской «отсутствует» помечать нельзя.

## Ответ на памятку (стр. 23–28): для каждой песни

Полная таблица — `book_summary.json` → `per_sarga_aligned` (сарги сопоставлены **по содержанию**, не по
номеру). Пример (крит.→южн., шлок крит / шлок южн / Δ): 1→1 190/213 (+23) · 3→3 37/51 (+14) · 4→5 24/27 ·
… · 66→68 29/29 (0). Δ по сопоставленным саргам малы (0–23) — это реальные поверсные различия.

⚠️ **Не используйте** `per_sarga_by_number_RAW` (сравнение по номеру сарги) — оно вводит в заблуждение
после первого структурного расхождения (напр. «сарга 58 +147» — артефакт сдвига нумерации, а не реальное
различие).

## Значимые отсутствия — кандидаты в сноски

`significant_absences.json` — южные пассажи, не выровненные с критическим. **Фильтровать по `divergence`:**
сноску «В критическом издании (Барода) отсутствует» ставить только для **`structural_absence` (307 шлок)**;
`reworded` (435) — это разночтения, не отсутствия. Целые южные сарги (+2) — всегда отсутствие. Крупнейшие

## Как ещё отмечены отличия (файлы)

- `book_summary.json` — счётчики, `per_sarga_aligned`, `southern_extra_sargas`, book totals.
- `concordance.json` — построчный кросс-волк крит.↔южн. (`identical` / `variant` / `southern_only` /
  `critical_only`) — таблица-конкорданс нумерации.
- `significant_absences.json` — южные пассажи без критического аналога (сноски «отсутствует в критическом»),
  сгруппированы в непрерывные пассажи (runs).
- `critical_only_and_variants.json` — шлоки только в критическом + пары словесных вариантов (с
  similarity-оценкой).

## Оговорки (точность) — обновлено после п.1 (канонизация `sanskrit_util`)

Надёжны: **счёт сарг (66 vs 68 = +2), счёт шлок (2488 vs 2859, +371), крупные непрерывные южные
пассажи**. Канонизация теперь принципиальная (`sanskrit_util.nfold`, п.1): идентичных стало 1065,
добавлено выявление транспозиций и отделение «истинных отсутствий» (canon нигде в др. издании) от
кажущихся. **Но `critical_only` (399) НЕ сократился до ожидаемого <50**: остаток — не орфография (её
canon снял), а то, что глобальное LCS-выравнивание (difflib) оставляет несопоставленными шлоки, у которых
в южном есть *вариантный* (не точный) аналог. Настоящих «только в критическом» шлок в Рамаяне мало → 399
всё ещё в основном артефакт выравнивания. **Следующий шаг (не сделан):** нечёткое глобальное назначение
(каждую `critical_only` сопоставить лучшему кандидату в южном по `sa_align.sim`, а не только по позиции
LCS). Идентификация «лишних» сарг (4/8/60) тоже требует сверки. Редактору сверять конкретные пассажи с
печатным критическим аппаратом.
